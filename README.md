## 💻 Visualisation Locale

Ouvrez simplement le fichier `index.html` dans n'importe quel navigateur web moderne :

```bash
# Double-cliquez sur index.html ou lancez un serveur local léger :
npx serve .
# ou avec python :
python -m http.server 8000
```

Rendez-vous ensuite sur `http://localhost:8000`.

## 🌐 Déploiement sur GitHub Pages

Pour publier votre portfolio gratuitement en ligne sur `https://ambinintsoa01.github.io/Mon_Portfolio/` :

1. Poussez votre code sur GitHub :
   ```bash
   git add .
   git commit -m "Portfolio complet inspiré de Gerold avec projets GitHub"
   git push origin main
   ```
2. Sur GitHub, rendez-vous dans **Settings** > **Pages**.
3. Sous **Build and deployment** / **Source**, choisissez `Deploy from a branch`.
4. Sélectionnez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
5. Votre portfolio sera en ligne en quelques secondes !
